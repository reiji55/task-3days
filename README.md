# 3日間タスク

昨日・今日・明日の3日分と、日付に紐づかない「いつでも」を表示するタスクビューア。
チェック・メモ・思いついたことの追加は画面からでき、`tasks.txt` に保存される。
**画面の下の3つのしるしで切り替える。真ん中がタスク、右が週、左がガイド**
（やり方の書き置き場）。横になぞっても送れる。**開くのはいつも真ん中のタスクから。**

- 公開URL： https://reiji55.github.io/task-3days/
- 編集するファイル： [`tasks.txt`](../../edit/main/tasks.txt)

管理はしない。実体は Google カレンダー、詳細は Obsidian。ここは3日分の作業台。

---

## 編集を有効にする

初期状態は読み取り専用。**「設定」を開いて暗証番号を入れる**と編集できるようになる。

**GitHub のトークンはブラウザに置かない。** 書き込みは `mcp/` の Vercel を経由し、
トークンはあちらの環境変数にある。この画面が持つのは暗証番号だけ。

### 消えても困らないようにする

iOS Safari は7日間開かなかったサイトの保存領域を消す。ホーム画面のアプリと
Safari でも保存領域が別なので、片方で入れても他方には無い。

**`?k=暗証番号` を付けた URL をホーム画面に追加しておけば、記憶が消えても効く。**

```
https://reiji55.github.io/task-3days/?k=0402
```

暗証番号を変えるときは Vercel の `EDIT_PIN` を書き換えて再デプロイする。

## できること

| 操作 | 結果 |
|---|---|
| チェックをタップ | `- [ ]` ⇄ `- [x]` を書き換える。**その場で変わる** |
| メモをタップ | メモを書き換える。空にすると行ごと消える |
| カードをタップ | `＋メモ` `＋引き継ぎ` が出る。空の欄の追加ボタンは普段しまってある |
| **終日**のカードをタップ | 畳んである中身が開く。タグ・メモ・引き継ぎが出る |
| カードを**左へ払う** | 赤い `削除` が出る。叩くと消える（メモの行も一緒に） |
| カードを**右へ払う** | 緑の面が出る。叩くと `MUST へ`（未完了タブでは `今日へ`） |
| 時刻をタップ | 輪を回して時間帯を決める（`終日` も同じ場所に出て、同じく叩ける） |
| 右上の `✕` をタップ | 確認のうえタスクを削除。払うのと同じ結果 |
| 一番上の入力欄 | 書いて `＋`（または Enter）で「いつでも」に足す |
| 日付のタブ | その日だけを出す。今日には `今日 9/11` と併記する |
| 下の3つのしるし | 表示を切り替える。横になぞっても送れる。開き直すといつも真ん中に戻る |
| 更新 | 読み直す。他の端末や Claude 側の変更を取り込む |

時間帯・型・プロジェクトを付けたい、日付を決めて入れたい、まとめて繰り越したい
——このあたりは Claude に頼む（`mcp/` のコネクタ経由）。
手で直したいときは `tasks.txt` を GitHub 上で編集してもよい。

### 日付のタブ

**1日ずつ出す。** 上に `9/10` `今日 9/11` `9/12` と並び、選んだ日の分だけを描く。
選んでいないタブには、**残っている件数をオレンジの数字**で出す。

1日の中は **MUST → 終日 → タイムライン → いつでも** の順。札の形はどの画面でも同じで、枠を持たず
**左の帯の色だけで見分ける**。タイムラインは案件ごとに1色、それ以外は黒とグレー
（黒＝いま背負っているもの、グレー＝日付の無いもの・先の話）。左端も揃えてある。

タイムラインは時刻の順に並べ、左に始まりの時刻、札の上に案件名と終わりの時刻を置く。
今日だけは**現在時刻の赤い線**が入り、進行中の枠が薄く色づく。

**時刻は札の中ではなく、左の欄に出す。**タイムライン・MUST・終日、どれも同じ位置・
同じ大きさで、叩けば輪が出る。畳んだ札の中に小さく入れていると、どこから直せるのか
分からないため。範囲があるものは**始まりだけ**（`09:00-10:00` → `09:00`）、
終日は `終日` とそのまま出す。

**終日は題だけに畳んである。** 下に小さく案件名と「メモあり」「引き継ぎあり」だけ出る。
叩くと開いて、タグ・メモ・引き継ぎ・追加ボタンが出る。開けたままにしておけば、
他の札を触って画面が描き直されても開いたまま。日付のタブを移ると畳み直す。

過ぎた日のタブには `まとめて今日へ` が出る。押すと**未完了のぶんをメモと引き継ぎごと
今日の末尾へ移す**（終わったぶんはその日に残る）。

### MUST

**今日これだけは、を1段目に立てる。** 札を**右へ払うと `MUST へ` が出て、
開いたまま止まる。叩いて初めて入る**。MUST の札を右へ払えば `MUST を外す` が出て、
同じ2手で元へ戻る。削除と同じ手順なので、払った勢いだけでは何も起こらない。

**位置は動かさない。**`tasks.txt` には印の行を1本足すだけ。

```
- [ ] 10:00-12:00 | 前進 | 転職 | 方針を固める
  must: 1
```

動かして戻す作りだと「元あったところ」を覚えておく必要があるが、印なら
外した瞬間にいつもの並び（終日・時刻順）へそのまま戻る。消すときも繰り越すときも、
`memo:` `next:` と同じようにこの行を連れていく。

**左も右も「払って開く → 叩く」の2手で揃えてある。**右に何が出るかだけが
場所で変わる（ふつうの日は `MUST`、未完了タブは `今日へ`）。
面の字は `--on-fill` で置く。暗いところでは地の色が明るい方に振ってあるので、
白のままだと沈んでしまう。

### 未完了のタブ

3日の窓から外れた日は、**まとめて先頭の `未完了` タブ**に入る。
残っているものだけを日付ごとに並べ、ここでも `まとめて今日へ` で何日分でも一度に送れる。
明後日より先の予定があれば、線で区切って `先の予定` として下に付ける。
どちらも無ければ、このタブ自体が出ない。

**札を右へ払うと `今日へ` が出る。**押すとその1本だけを、メモ・引き継ぎごと
今日の末尾へ送る。全部まとめて送るほどではないときに使う。

このタブには、**週の時間割で取りこぼした枠も自動で入ってくる**。
写しを入れ替えるとき、`❌` を付けたものと印が無いまま過ぎたものを
枠のあった日付のままタスクにする（→ [取りこぼしは消える前に拾う](#取りこぼしは消える前に拾う)）。

### 案件の色

**同じ案件は、3つの面のどこでも同じ色。**ガイドのカード・タスクの案件タグ・
週の予定が、1つの表を引いている。

色は**名前**で決まる。並び順ではないので、ガイドのカードを1枚足しても
後ろの色はずれない。順番は「ガイドのカード → タスクの案件 → 週の予定」で、
先に出てきた名前から `--p1`〜`--p8` を順に配る。

### タスクとガイドの行き来

タスクは「いま何をするか」、ガイドは「どうやるか」。**案件名で結んである。**
名前がどちらかに含まれていれば同じものとみなす（`TOEIC` と `TOEIC対策`）。

| どこ | 何が出るか |
|---|---|
| タスクの案件タグ | 当たるカードがあれば点線の下線。叩くとそのガイドが開く |
| ガイドのカード | 当たる未完了の**居場所と数**（`未完了 2件・今日 1件`） |

点線のタグから飛んだときは、ガイドの `←` で**元いた面へ帰る**。
一覧に落とすと「見に来ただけ」なのに置き去りにされた感じになるため。
ガイドのタブから開いたぶんは今までどおり一覧へ戻る。

カードの内訳は**読むだけで、叩けない。**3日の面へ飛ばしても
どこへ連れて行かれたのか分からないので、居場所を名前で出す方にした。
並びは画面のタブと同じ（`未完了 → 昨日 → 今日 → 明日 → いつでも → 先の予定`）。

ガイドは開く前から読んでおく（色と結びつけに要るため）。

### メモと引き継ぎ

**メモは自分用のおぼえ書き、引き継ぎは Claude への依頼**、と使い分ける。
引き継ぎは緑の枠で出るので、どちらか一目で分かる。

```
- [ ] 19:00-21:00 | 前進 | 転職 | 職種リストを作る
  memo: 中間成果物。単体で残る形にする。
  next: 求人サイト3つから未経験可の職種名だけ拾ってきて
```

Claude はこれを読んだら拾って動き、済んだら何をしたかを `memo` に書いてから
`next` を空にする。`引き継ぎ:` と日本語で書いてもよい。

### いつでも

日付を決めずに残しておく置き場。**どの日付のタブにも一緒に出る。**
思いついた小さい用事を、日付を考えずに入れておくためのもの。

入力欄はタグを付けない。時間帯やプロジェクトが要るなら、あとから Claude に頼むか
`tasks.txt` を直接直す。日付が決まったら `move_tasks` でその日に移せる。

**消したタスクも履歴には残る**ので、間違えて消しても GitHub から拾える。

### 待たされない

タップした瞬間に手元のテキストを直して描き直す。**サーバーの返事は待たない。**

| | |
|---|---|
| チェック・追加・削除 | 指が止まってから **0.5秒**でまとめて1回保存 |
| メモ・引き継ぎ | 打鍵が止まってから **1秒**。1文字ごとには送らない |
| 出していない間 | 右上に小さく「保存中…」。済んだら消える |
| 済んだとき | 何も出さない |
| しくじったとき | 下に数秒だけ知らせが出て、**操作する前の状態に戻る** |

入力欄の文字は 16px 以上にしてある。これより小さいと **iOS が入力のたびに画面を拡大し、
キーボードを閉じても戻さない**。メモを閉じたときは、書いていた札が同じ高さに留まるよう
スクロールを合わせ直す（キーボードが閉じきるまで見張る。指が動いたらやめる）。

**5個続けてチェックを付けても、コミットは1本。**付けてすぐ外す、打って「やめる」、
のように行って帰ってきただけなら、中身が同じなので保存しない。

別の端末に先を越されていたら、**最新を取り直して同じ操作を当て直し、もう一度だけ送る。**
自分の分も相手の分も残る。それでも駄目なら諦めて読み直し、下に理由を出す。

出していない分があるうちは `更新` を押しても取り直さない（打った分が消えるため）。
閉じようとしたときは残りを投げてから閉じる。それも間に合わないときは離脱を止める。

## 週の時間割

下の右のしるし（カレンダー）で、月曜〜日曜の1週間を1画面に出す。
**縦が日付、横が時刻。**7日ぶんの帯が上から月・火…と並び、左から右へ時間が流れる。
**Google カレンダーの写し**を [`week.json`](week.json) に持っていて、画面はそれを描いているだけ。

**縦軸の終わりは夜勤に合わせて自動で延びる。** `end_hour` は既定 26（翌2時）だが、
21:00〜翌5:00 のような予定があると、写しを作るときに 29（翌5時）まで延ばす。
延ばさないと終わりの3時間が黙って消えて、いつ終わるのか画面にも紙にも出ない。
延ばすのは丸1日ぶん（`start_hour + 24`）まで。

**7行ぶんが日曜まで必ず1画面に収まる。**行の高さは決め打ちではなく、
描いたあとにタブの位置まで測って合わせている（iPhone SE でも 6.7インチでも同じ）。
はみ出すのは下の一覧だけで、そちらはスクロールして見る。

| | |
|---|---|
| 更新 | **毎週月曜の朝に自動**。カレンダーを読んで `week.json` を入れ替える |
| 横の目盛り | その週に予定がある時間だけに寄せる（前後1時間の余裕つき）。多くても9本 |
| いまの時間 | 目盛りのその数字が黒く塗られる |
| 今日 | 帯の地が1段明るくなり、赤い印と点線が今の時刻に立つ |
| 日付をタップ | その日を下の一覧に出す |
| 帯をタップ | その日を下の一覧に出す。**叩いた帯を数秒囲う**。印は動かない |
| タスクの札をタップ | その日に切り替え、**下の一覧の当人まで送って光らせる** |
| 薄い斜めの枠 | 「睡眠」「生活時間」など、先に抜いておく時間。タップできない |
| 色 | 予定の名前（`｜` や `／` の前）ごとに自動で振る。暗いところでは明るい方の色に振り替わる |
| 見出しの横 | 写しが古いと「◯週前の写しです」と赤く出る |
| `印刷` | A4横1枚に組み直して印刷。iPhone なら「PDFとして保存」でコンビニに持っていける |

**入らなかった名前は、その日の帯の下に回す。**幅は分単位で決まるので、
30分の予定に日本語は入らない。描いたあとに実物を測って、あふれたものだけ
`● 14:00 打ち合わせ` のような小さな札にして下の行へ落とす。
帯の中は空にするので、読めない字が潰れて残ることはない。

### 叩いたものを返す

表の札も帯も、叩いても画面がほとんど変わらない。何に触ったのか分からないので、
**叩いたものをその色で数秒だけ囲って返す。**

| 叩いたもの | 返るもの |
|---|---|
| 帯（名前が中に入っている） | その帯を囲う |
| 帯（名前が下の札に回っている） | 下の札を囲う |
| タスクの札 | **下の一覧の当人まで画面を送って**、その札を囲う |

タスクの札は名前を持てない（1時間で19px しかない）ので、送ってやらないと
「どれを叩いたのか」を確かめようがない。囲いは 2.6 秒で消え、
別のものを叩けば古い囲いは消える。いま何を選んだのかは常に1つ。

### いま、どこにいるか

**その日の頭から現在時刻までを、一本の帯で塗る。**枠の中だけでなく空いている
時間も塗るので、どこまで来たかが形で分かる。

```
月〜木   端まで塗ってある      → もう済んだ日
金       途中で切れている      → 今日。切れ目が今の時刻
土・日   塗っていない          → これからの日
```

塗ったところと塗っていないところで地の色が変わり、今日の切れ目には
**赤い線と丸い印**が立つ。その位置から下に点線が伸びるので、他の曜日の
同じ時刻と見比べられる。上の目盛りも、今を含む一つだけ黒く塗る。

暗いところでは、塗りを薄めに掛ける。強く塗ると過ぎた日が読めなくなるため。

### 取りこぼしは光る

**終わりの時刻を過ぎたのに印が無い枠は、マゼンタに光る。**ゆっくり明滅する。

他の予定は時間が過ぎると上の帯に沈んでいくのに、**光る枠だけは沈まない**。
帯より手前に出して、暗がりのペンライトのように残す。

```
⭕️ が付いている     斜線。過ぎた帯に沈む
❌ が付いている     何もしない。過ぎた帯に沈む
どちらも無い        光る ← 手を付けたかどうかも決めていない
```

`❌` を付ければ光りは消える。「やらないと決めた」ことも一つの結論なので、
残るのは**まだ何も決めていないもの**だけになる。印を付けたその場で消える。

**光っているものを拾うのは、写しを入れ替えるときだけ**（→
[取りこぼしは消える前に拾う](#取りこぼしは消える前に拾う)）。
以前は下の一覧に `タスクにする` を置いていたが、押したぶんは「いつでも」に入り、
入れ替えで拾うぶんは枠のあった日付に入るので、**同じものが2本できてしまう**。
入り口は1つに絞った。いま手を付けるなら、`❌` を付けてから3日の面で足す。

動きを減らす設定（`prefers-reduced-motion`）のときは、明滅させずに光らせたままにする。
紙に刷るときは光らせない。

**面は横になぞって送る。** 並びは 左=ガイド／中=タスク／右=週。
iPhone のホーム画面と同じで、指について動き、
離すと近い方に吸い付く。半分近くまで動かせば送られ、足りなければ戻る。
端ではそれ以上動かないよう重くなる。

拾わないもの：左右の端から始めた指（Safari の「戻る」）、縦に動かしている指、
そして**タスクの札の上で始めた指**（そちらは札を払って削除に使う）。
3日の面から送りたいときは、札の外か、下のしるしで。

**縦の位置は動かさない。**送り終わったところでそのまま止まる。送っている間ずっと
見えていた位置なので、指を離した瞬間に画面が飛ばない。ボタンで送っても指で送っても同じで、
行き先の方が短ければそこの下端で止まる。

開き直すといつも真ん中のタスクから始まる。
`?v=week` を付けた URL のときだけ、いきなり週の画面を開ける。

```
https://reiji55.github.io/task-3days/?k=0402&v=week
```

### やったか、やらなかったか

印は**下の一覧だけ**で付ける。表の帯をタップしてもその日に移るだけで、印は動かない。
一覧の札をタップすると、3つの状態を順に回る。

```
印なし  →  ⭕️ やった  →  ❌ やらなかった  →  印なし
```

左に**点線の四角い枠**が空いていて、そこへ印がそのまま収まる。
⭕️ は緑、❌ は赤で、枠いっぱいに塗った四角い判子が跳ねて入る。

**やった予定は、表の中で斜線に覆われる。**予定の色そのままの太い斜線を、
文字の上からそのまま被せる。名前は透けて読めるが、一目で「済んだ列」と分かる。
下に回した札のほうには `済` が付く。

**❌ は表を何も変えない。**手を付けなかった予定は白いまま残るので、
「そもそも動かなかった」ことがそのまま見て取れる。

編集を有効にしているときだけ変えられる（`tasks.txt` と同じ）。

印は `week.json` の `status` に入り、**写しを取り直しても消えない**
（時刻と名前が同じものに引き継ぐ。予定そのものが変わったら引き継がない）。

`❌` を付けたものは「やらなかった枠」として Claude から読める。
**「やらなかった枠をカレンダーから消して」と頼めば、一覧を出したうえで消す。**
勝手には消さない。誤タップで予定が消えると取り返しがつかないため。

**予定そのものはここでは編集しない。** 実体は Google カレンダーで、二重管理にすると
どちらが正しいか分からなくなる。予定を変えるならカレンダーを直して、
Claude に「週の時間割を取り直して」と言えば写しが入れ替わる。

### タスクを時間割に重ねる

**時刻の決まったタスクは、その時刻の場所に小さい札で乗る。**
繰り越したタスクが「寝ている時間」に入っていないか、予定とぶつかっていないかを
一目で見るためのもの。`week.json` には何も書かない。読んで重ねているだけ。

| タスクの状態 | 札の見え方 |
|---|---|
| ふつう | 案件の色で縁取った白い丸札 |
| MUST | 中に **★** |
| 済み | 予定の枠と同じ**斜線** |

**どの札にも案件の色で薄く後光を差す。**帯の上に乗っているものを地から浮かせるための
見た目で、状態の合図ではない。済みも、時間が過ぎたものも、同じように付く。

- **名前は載せない。** 1時間ぶんの幅が 19px しかないので、どう詰めても入らない
- 出すのは**時刻のあるものだけ**。終日・いつでも・「午前」などは置き場所が無い
- **縦軸の窓（`start_hour`〜`end_hour`、中身に合わせて自動で絞る）の外は出さない**
- 過ぎたところを塗る面より**上**に置く。自分の持ち物は時間が過ぎても沈めない
- **紙には出さない。** この幅では印しか刷れないうえ、中身は毎日動く
- 見た目は 20px だが、**指はその外側 7〜9px まで受ける**

**名前を読むのはグリッドの下。**「◯月◯日の予定」に続けて `この日のタスク` の節が出る。
ここには名前・時刻・案件と、**ぶつかっている予定の名前**（`仕事 と重なっています`）が並ぶ。
薄く出している `睡眠` も相手として数える——寝ている時間に置いてしまうのが、
そもそもの困りごとなので。札を叩くと3日の面のその日へ飛ぶ
（3日の窓から外れた日なら `未完了` のタブへ）。

### 時間帯を回して決める

**時刻の札を叩くと、下から輪が4つ出る。**かちかち吸い付くので、片手で回して決められる。

| どこから開くか | |
|---|---|
| タイムラインの札 | 左の**始まりの時刻**を叩く |
| 終日・いつでもの札 | 開いてから `終日` の札を叩く |
| 時刻の無いタスク | 開いて `＋時間` |

- 分は**5分きざみ**
- `終日にする` でタイムラインから外す。`時間を消す` で欄ごと空にする
- **追い越したら、触っていない方の輪が動いて長さを保つ。**
  始まりを後ろへ回せば終わりが押し出され、終わりを前へ回せば始まりが引かれる。
  動かすのは常に逆側——指の下の輪が動くと、何が起きたのか分からなくなる
- **つまみのあたりを下へ払っても閉じる。**輪とボタンの上の指は取らない
- 書き換わるのは `tasks.txt` の**時間帯の欄だけ**。`memo:` `next:` `must:` はそのまま

### 長押しで1時間ずつずらす

**時刻を押さえたまま指を上下に振ると、始まりと終わりが一緒に動く。**長さは変わらない。
離すとその場で入る。「1時間後ろへ」くらいの直しに、ダイヤルを出すのは手数が多いため。

- **下でうしろへ、上でまえへ。**3日の面は時間が上から下へ流れているので、それに合わせた
- 横にしなかったのは、札を払う（削除・MUST）と面を送るで既に埋まっているため
- 1時間ぶん＝指の 40px。押さえてから **420ms** で出る
- 動かさずに離したら何もしない。**離した直後の1回はダイヤルを出さない**
- 終日など、ずらす先の無いものでは出ない（叩けばダイヤルは開く）

**時刻の上では、iOS が長押しを自分のものにする仕掛けを全部切ってある。**

| 切るもの | 切らないと |
|---|---|
| `-webkit-touch-callout` | 長押しでコピー等の吹き出しが出る |
| `user-select` | ずらしている間にページの文字が選ばれていく |
| `touch-action` | 指なりの画面送りに取られる |

ずらしている間は `body.holding` で**ページ全体の文字選択も止める**（指が他の
文字の上を通るため）。取られると「ずれるのに、指を離しても HUD が閉じない」という
出方をする——離す合図がこちらに来なくなるため。

保険として、**HUD が出たまま残っても次にどこかを触れば必ず消える**。
出しっぱなしで操作を塞がないようにしてある。

### 時刻だけ別の書体

時刻は `ui-rounded`（無ければ本文と同じ書体）で、太さも一段上げてある。
本文に数字が埋もれると、**叩ける場所が見つけにくい**ため。文章の書体はそのまま。

### 取りこぼしは消える前に拾う

写しを入れ替えると、先週の枠はまるごと消える。そのとき**消える枠のうち
`❌` を付けたものと、印が無いまま時間だけ過ぎたもの（画面で光っていたもの）は、
自動で `tasks.txt` に移る。** この2つは「やらなかった」という意味では同じなので、
区別せず同じ扱いにしている。

- **枠があった日付のまま**入るので、画面では `未完了` のタブに出る
- `⭕️` と、まだ来ていない枠と、薄く出している枠（睡眠など）は拾わない
- 同じ日に同じ名前のタスクが既にあれば足さない（呼び直しても二重にならない）
- 拾うのは**週を書き換える前**。順番が逆だと、タスク側が転んだときに消えてしまう
- 週の途中で取り直しても、残る枠は拾わない。**消える枠だけ**が対象

何を移したかは `set_week` の戻りの `carried` に入る。

### 紙に出す

`印刷` を押すと **A4横1枚**に組み直す。**紙は画面の写しではない。**
横幅が 264mm あるので、狭いスマホの画面で諦めたものを全部戻す。

| | 画面 | 紙 |
|---|---|---|
| 目盛り | 2時間おき（幅が足りない） | **1時間おき** |
| 方眼 | 目盛りに合わせた粗い線 | **1時間おきの線** |
| 名前 | 入らない分は帯の下の札へ | **全部、帯の中に入れる** |
| 行の高さ | 画面の残りから実測 | **紙の残り一杯（23mm）** |
| 済んだ枠の斜線 | 濃い | **薄い**（字を読ませるため） |
| 今の時刻・過ぎた帯・光る枠 | 出す | **出さない** |

現在位置を刷らないのは、刷った瞬間から古くなるため。曜日・日付・予定・時間だけが残る。

**紙の色は、端末が暗いところ用の設定でも明るいところ用で出す。**色の名前を
一つでも戻し忘れると、その名前を読んでいる枠だけが真っ黒で刷られる
（枠の地は `color-mix(… var(--panel))` なので、`--panel` が暗いと黒くなる）。
だから `@media print` では色の名前を全部引き直している。

行の高さは 20mm。刷れる高さは 194mm あるが、Safari は上下に URL と日付・
ページ番号を自前で足すので、目一杯まで使うと日曜が2枚目にこぼれる。

iPhone なら プリント画面で**ピンチアウト → 共有 → 「ファイルに保存」で PDF になる**。
それをコンビニのアプリに渡せばそのまま印刷できる。

手書きで書き込む前提のもっと余白の広い版は weekplan スキルが別に出す。
`week.json` は**そのスキルの `events.json` と同じ形**なので、同じデータから
紙もスマホも作れる。

## ガイド

下の左のしるし（しおり）で、**やり方を書いておく場所**が出る。
タスクは「いま何をするか」、ガイドは「どうやるか」。ルーチンの手順や、
じっくり書いておきたい案件の中身を置く。日付にも3日の窓にも縛られない。

**一覧は色の付いた札が重なっているだけ。**日付と見出ししか出ていない。
**札をタップすると、その色のまま全画面に広がり、下から白い面がせり上がる。**

| 操作 | 結果 |
|---|---|
| 札をタップ | 開く。札の色がそのまま画面になる |
| 上へなぞる | `Detail` は下の方にいる。引き上げて読む・書く |
| `Purpose` / `Goal` | 長い文になるので、ラベルを上に置いて左から読ませる |
| 下へなぞる | 元の位置に戻す |
| 帯（面の上の短い線）をタップ | 上げ下げを切り替える |

**引き上げるのは、帯でも `Detail` の本文でも掴める。**色の面は `Purpose` や
`Goal` が入っているところだけが指を受ける（その下の色だけの帯は何もしない）。

白い面が上まで来ているときだけ、本文の上の指は**読むための指**として
スクロールに返す。下ろしたいときは、本文の先頭から下へ引くか帯を使う。

白い面は画面と同じ高さのまま下へずらしてあるので、**中身の箱もその分だけ
画面の外にはみ出す。**はみ出した分を下の余白で埋めてあり、埋めないと
最後まで送っても終わりの数行が画面の外に残って読めない。
| 色の上を**横に払う** | 隣のカードへ。何枚目かは丸い印で分かる |
| 色の上を**下に払う** | 一覧に戻る（左上の `‹` でも同じ） |
| `Search` | 見出しと中身をまとめて探す |

| 欄 | どこに出るか | 中身 |
|---|---|---|
| 見出し | 色の面（大きい字） | そのまま打ち直せる |
| `Purpose` | 色の面 | なぜやるのか |
| `Goal` | 色の面 | どうなったら終わりか |
| `Created on` | 色の面 | 作った日。自動で入る |
| `Detail` | 白い面 | やり方・手順・覚え書き。何行でも |

編集を有効にしていれば、**どの欄もタップしてそのまま打てる**。
消すのは白い面のいちばん下の `このカードを削除`（履歴には残る）。

**足す入口は3日の面と同じ形**（`[ 打ち込む欄 ][ ＋ ]`）。打った文字がそのまま
見出しになるので、空のカードを作ってから名前を付け直さなくていい。

### 保存は自分で押す

打っても勝手には上がらない。**直すと `保存` が出るので、それを押すと
`board.json` に1コミット**される。一覧と詳細のどちらからでも押せる。

1. 打った瞬間に画面と端末（`localStorage`）に入る。ここは待たされない
2. **`保存` を押したときだけ** GitHub へ出す
3. 押さずに閉じても端末には残る。次に開くと「未保存の下書きがあります」と出て、
   `保存` を押せばそのまま上がる

いくつ直しても押すのは1回でよく、コミットも1本にまとまる。
未保存のまま `更新` を押しても取り直さない（打った分が消えるため）。

**GitHub をやめてはいない。** ここが消えると Claude から読めなくなるし、
iOS は7日開かないと端末の記憶を消してしまう。

読み込みは、**中身が本当にボードだと確かめてから**書き込み用の SHA を持つ。
サーバー側がまだ `?file=board` を知らない場合は `tasks.txt` が返るので、
そのまま信じると `tasks.txt` を潰してしまう。確かめが通らないときは書き込まず、
「いまは端末の中にだけ残ります」と先に伝える。

Claude 側からは `get_board` で読み、`set_board_card` で1枚ずつ書き足せる。
「このルーチンどうやるんだっけ」に、ここに書いた手順で答えられる。

`?v=board` を付けた URL で、いきなりガイドを開ける。

## 書き方

```
# 2026-08-28
- [ ] 20:00-21:00 | 前進 | AIトレード | ステータスを整理する
  memo: 次のタスクを切り出すところまで
- [x] 終日 | ルーチン | 仕事 | 現場（未定）

# いつでも
- [ ] 燃えるゴミを出す
```

| 位置 | 中身 | 省略 |
|---|---|---|
| `# YYYY-MM-DD` | 日付の見出し。この下に並べる | 不可 |
| `- [ ]` / `- [x]` | 未完了 / 完了 | 不可 |
| 1本目 `\|` の前 | 時間帯（`20:00-21:00`／`終日`／`午前`） | `-` で空欄 |
| 2本目 | 型（`前進` / `ルーチン`） | `-` で空欄 |
| 3本目 | プロジェクト名 | `-` で空欄 |
| 残り | タスク名 | 不可 |
| 次の行 `memo:` | メモ（自分用）。複数行可 | 省略可 |
| 次の行 `next:` | 引き継ぎ（Claude への依頼）。複数行可 | 省略可 |

- `//` で始まる行はコメント。表示されない
- 3日の窓から外れた日付は `未完了` のタブに入る。消さなくていい
- `# いつでも` は日付なしの置き場。どの日付のタブにも出る（`# anytime` でも同じ）
- `next:` は `引き継ぎ:` でも同じ。`memo:` と順番はどちらでもよい
- 日付の並び順は問わない

### 空になった過去の日は片付く

タスクを全部消すと日付の見出しだけが残る。**中身が無い過去の日は表示に出さず、
次に何か保存したときにファイルからも見出しごと消える。**

掃除のためだけのコミットは作らない。あなたが何か操作したときの保存に相乗りする。
触らないもの：3日の窓（昨日・今日・明日／空でも枠として要る）、今日以降の日付、
「いつでも」、コメントなどが残っている節。

## iPhone のホーム画面に置く

1. Safari で https://reiji55.github.io/task-3days/ を開く
2. 共有ボタン → **ホーム画面に追加**

アイコンが付き、Safari のバーが出ない全画面で開く。名前は「3日間タスク」。
アイコンの元は [`icon.svg`](icon.svg)。差し替えるときはここを直して PNG を作り直す。

### 画面が古いまま出るとき

ホーム画面のアプリは `index.html` を強く握るので、直しても端末には古いまま残る。
そこで **[`version.txt`](version.txt) だけは毎回取りに行き、`index.html` の
`<meta name="app-version">` と食い違ったら、URL に `?r=版` を足して読み直す。**
開き直したときにも見るので、放っておいても次に開いたときには新しくなる。

**`index.html` を直したら、この2か所を同じ値に揃えて上げること。**
揃っていないと、いつまでも読み直しが走り続ける（1セッションに1回で止まるが、
画面の右に「新しい版があります」と出たままになる）。

## 使い方

- **進んだらタップ**してチェックを付ける。メモもその場で書き換えられる
- **思いついたら入力欄に放り込む**。日付は決めなくていい（「いつでも」に入る）
- 日付を決める・まとめて入れ替えるときは Claude に頼む（`mcp/` のコネクタ経由）
- 手で直したいときは [`tasks.txt`](../../edit/main/tasks.txt) を GitHub 上で編集
- **今週の動きを見たい**ときは右の `週` に切り替える。予定はカレンダーの写し
- **やり方を書き残したい**ときは左の `ガイド`。タスクにせず、手順として置いておく

状態もメモも `tasks.txt` の中にあるので、次に相談するとき Claude がそのまま読める。
何が終わって何が残っているかも、そこから分かる。週の予定は `week.json`、
書き置きは `board.json` から読める。
