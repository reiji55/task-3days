# 3日間タスク

昨日・今日・明日の3日分と、日付に紐づかない「いつでも」を表示するタスクビューア。
チェック・メモ・思いついたことの追加は画面からでき、`tasks.txt` に保存される。
**画面の下の3つのしるしで切り替える。真ん中がタスク、右が週、左がガイド**
（やり方の書き置き場）。横になぞっても送れる。

- 公開URL： https://reiji55.github.io/task-3days/
- 編集するファイル： [`tasks.txt`](../../edit/main/tasks.txt)

管理はしない。実体は Google カレンダー、詳細は Obsidian。ここは3日分の作業台。

---

## 編集を有効にする

初期状態は読み取り専用。**「設定」を開いて暗証番号を入れる**と編集できるようになる。

**GitHub のトークンはブラウザに置かない。** 書き込みは `mcp/` の Vercel を経由し、
トークンはあちらの環境変数にある。この画面が持つのは暗証番号だけ。

### 消えても困らないようにする

iOS Safari は7日間開かなかったサイトの保存領域を消す。ホーム画面のアプリと
Safari でも保存領域が別なので、片方で入れても他方には無い。

**`?k=暗証番号` を付けた URL をホーム画面に追加しておけば、記憶が消えても効く。**

```
https://reiji55.github.io/task-3days/?k=0402
```

暗証番号を変えるときは Vercel の `EDIT_PIN` を書き換えて再デプロイする。

## できること

| 操作 | 結果 |
|---|---|
| チェックをタップ | `- [ ]` ⇄ `- [x]` を書き換えて保存 |
| メモをタップ | メモを書き換えて保存。空にすると行ごと消える |
| `＋メモ` をタップ | メモのない行にメモを足す |
| `＋引き継ぎ` をタップ | Claude にやってほしいことを書く欄を足す |
| 右上の `✕` をタップ | 確認のうえタスクを削除（メモの行も一緒に消える） |
| 一番上の入力欄 | 書いて `＋`（または Enter）で「いつでも」に足す |
| 下の3つのしるし | 表示を切り替える。横になぞっても送れる。次に開いたときも同じ面が出る |
| 更新 | 読み直す。他の端末や Claude 側の変更を取り込む |

時間帯・型・プロジェクトを付けたい、日付を決めて入れたい、まとめて繰り越したい
——このあたりは Claude に頼む（`mcp/` のコネクタ経由）。
手で直したいときは `tasks.txt` を GitHub 上で編集してもよい。

### メモと引き継ぎ

**メモは自分用のおぼえ書き、引き継ぎは Claude への依頼**、と使い分ける。
引き継ぎは緑の枠で出るので、どちらか一目で分かる。

```
- [ ] 19:00-21:00 | 前進 | 転職 | 職種リストを作る
  memo: 中間成果物。単体で残る形にする。
  next: 求人サイト3つから未経験可の職種名だけ拾ってきて
```

Claude はこれを読んだら拾って動き、済んだら何をしたかを `memo` に書いてから
`next` を空にする。`引き継ぎ:` と日本語で書いてもよい。

### いつでも

日付を決めずに残しておく置き場。**3日の窓の外だが畳まれない。**
思いついた小さい用事を、日付を考えずに入れておくためのもの。

入力欄はタグを付けない。時間帯やプロジェクトが要るなら、あとから Claude に頼むか
`tasks.txt` を直接直す。日付が決まったら `move_tasks` でその日に移せる。

保存は1回ごとに1コミット。何をいつ変えたかは履歴に残る。
別の場所で先に更新されていた場合は保存せず読み直すので、上書きで消えることはない。
**消したタスクも履歴には残る**ので、間違えて消しても GitHub から拾える。

## 週の時間割

下の右のしるし（カレンダー）で、月曜〜日曜の1週間を1画面に出す。5:00〜26:00（翌2時）の縦軸に
予定をブロックで置く。**Google カレンダーの写し**を [`week.json`](week.json) に
持っていて、画面はそれを描いているだけ。

| | |
|---|---|
| 更新 | **毎週月曜の朝に自動**。カレンダーを読んで `week.json` を入れ替える |
| 今日 | 列の枠が濃くなり、今の時刻に赤い線が入る |
| 予定をタップ | 下に名前・時刻・場所が出る |
| 薄い枠 | 「睡眠」「生活時間」など、先に抜いておく時間 |
| 色 | 予定の名前（`｜` や `／` の前）ごとに自動で振る |
| 見出しの横 | 写しが古いと「◯週前の写しです」と赤く出る |
| 過ぎた時間 | 現在時刻より手前は色が落ちる。またいでいる枠は過ぎた分だけ |
| `印刷` | A4横1枚に組み直して印刷。iPhone なら「PDFとして保存」でコンビニに持っていける |

**面は横になぞって送る。** 並びは 左=ガイド／中=タスク／右=週。
iPhone のホーム画面と同じで、指について動き、
離すと近い方に吸い付く。半分近くまで動かせば送られ、足りなければ戻る。
端ではそれ以上動かないよう重くなる。

拾わないもの：左右の端から始めた指（Safari の「戻る」）と、縦に動かしている指。

`?v=week` を付けた URL で、いきなり週の画面を開ける。

```
https://reiji55.github.io/task-3days/?k=0402&v=week
```

### やったか、やらなかったか

**予定をタップ → 下に出た枠をタップ**すると、印が3つの状態を順に回る。

```
印なし  →  ⭕️ やった  →  ❌ やらなかった  →  印なし
```

印は予定の枠いっぱいに重なって出るので、週を開いた瞬間に見て分かる。
編集を有効にしているときだけ変えられる（`tasks.txt` と同じ）。

印は `week.json` の `status` に入り、**写しを取り直しても消えない**
（時刻と名前が同じものに引き継ぐ。予定そのものが変わったら引き継がない）。

`❌` を付けたものは「やらなかった枠」として Claude から読める。
**「やらなかった枠をカレンダーから消して」と頼めば、一覧を出したうえで消す。**
勝手には消さない。誤タップで予定が消えると取り返しがつかないため。

**予定そのものはここでは編集しない。** 実体は Google カレンダーで、二重管理にすると
どちらが正しいか分からなくなる。予定を変えるならカレンダーを直して、
Claude に「週の時間割を取り直して」と言えば写しが入れ替わる。

### 紙に出す

`印刷` を押すと、画面の見た目のまま **A4横1枚**に組み直す。1時間あたり 7.6mm、
ヘッダーや操作欄は落として時間割だけにする。

iPhone なら プリント画面で**ピンチアウト → 共有 → 「ファイルに保存」で PDF になる**。
それをコンビニのアプリに渡せばそのまま印刷できる。

手書きで書き込む前提のもっと余白の広い版は weekplan スキルが別に出す。
`week.json` は**そのスキルの `events.json` と同じ形**なので、同じデータから
紙もスマホも作れる。

## ガイド

下の左のしるし（しおり）で、**やり方を書いておく場所**が出る。
タスクは「いま何をするか」、ガイドは「どうやるか」。ルーチンの手順や、
じっくり書いておきたい案件の中身を置く。日付にも3日の窓にも縛られない。

**一覧は色の付いた札が重なっているだけ。**日付と見出ししか出ていない。
**札をタップすると、その色のまま全画面に広がり、下から白い面がせり上がる。**

| 操作 | 結果 |
|---|---|
| 札をタップ | 開く。札の色がそのまま画面になる |
| 白い面を上へなぞる | 上まで上げて、長い文章を読む・書く |
| 白い面を下へなぞる | 元の位置に戻す |
| 帯（面の上の短い線）をタップ | 上げ下げを切り替える |
| 色の上を**横に払う** | 隣のカードへ。何枚目かは丸い印で分かる |
| 色の上を**下に払う** | 一覧に戻る（左上の `‹` でも同じ） |
| `Search` | 見出しと中身をまとめて探す |

| 欄 | どこに出るか | 中身 |
|---|---|---|
| 見出し | 色の面（大きい字） | そのまま打ち直せる |
| `Purpose` | 色の面 | なぜやるのか |
| `Goal` | 色の面 | どうなったら終わりか |
| `Created on` | 色の面 | 作った日。自動で入る |
| `Detail` | 白い面 | やり方・手順・覚え書き。何行でも |

**白い面は `Created on` のすぐ下で休む。**欄の量に合わせて毎回測るので、
色の面に隙間が空かない。

編集を有効にしていれば、**どの欄もタップしてそのまま打てる**。保存ボタンは無い。
右上の `＋` で1枚足し、白い面のいちばん下の `このカードを削除` で消す（履歴には残る）。

### 保存を待たない

タスクと違って、ガイドは**書き込みの往復を待たない**。

1. 打った瞬間に画面と端末（`localStorage`）に入る
2. **手が止まって約1.2秒後**に、裏で `board.json` に1コミット
3. アプリを閉じるときも、残っていれば出してから閉じる

続けて打っている間は何度打ってもコミットは増えず、止まったところで1本にまとまる。
圏外で失敗しても端末には残っていて、次に開いたときに上げ直す。

**GitHub をやめてはいない。** ここが消えると Claude から読めなくなるし、
iOS は7日開かないと端末の記憶を消してしまう。**残す先は GitHub のまま、
待つのをやめた**という作りにしてある。

読み込みは、**中身が本当にボードだと確かめてから**書き込み用の SHA を持つ。
サーバー側がまだ `?file=board` を知らない場合は `tasks.txt` が返るので、
そのまま信じると `tasks.txt` を潰してしまう。確かめが通らないときは書き込まず、
「いまは端末の中にだけ残ります」と先に伝える。

Claude 側からは `get_board` で読み、`set_board_card` で1枚ずつ書き足せる。
「このルーチンどうやるんだっけ」に、ここに書いた手順で答えられる。

`?v=board` を付けた URL で、いきなりガイドを開ける。

## 書き方

```
# 2026-08-28
- [ ] 20:00-21:00 | 前進 | AIトレード | ステータスを整理する
  memo: 次のタスクを切り出すところまで
- [x] 終日 | ルーチン | 仕事 | 現場（未定）

# いつでも
- [ ] 燃えるゴミを出す
```

| 位置 | 中身 | 省略 |
|---|---|---|
| `# YYYY-MM-DD` | 日付の見出し。この下に並べる | 不可 |
| `- [ ]` / `- [x]` | 未完了 / 完了 | 不可 |
| 1本目 `\|` の前 | 時間帯（`20:00-21:00`／`終日`／`午前`） | `-` で空欄 |
| 2本目 | 型（`前進` / `ルーチン`） | `-` で空欄 |
| 3本目 | プロジェクト名 | `-` で空欄 |
| 残り | タスク名 | 不可 |
| 次の行 `memo:` | メモ（自分用）。複数行可 | 省略可 |
| 次の行 `next:` | 引き継ぎ（Claude への依頼）。複数行可 | 省略可 |

- `//` で始まる行はコメント。表示されない
- 3日の窓から外れた日付は「その他の日」に畳まれる。消さなくていい
- `# いつでも` は日付なしの置き場。畳まれず、いつも見える（`# anytime` でも同じ）
- `next:` は `引き継ぎ:` でも同じ。`memo:` と順番はどちらでもよい
- 日付の並び順は問わない

### 空になった過去の日は片付く

タスクを全部消すと日付の見出しだけが残る。**中身が無い過去の日は表示に出さず、
次に何か保存したときにファイルからも見出しごと消える。**

掃除のためだけのコミットは作らない。あなたが何か操作したときの保存に相乗りする。
触らないもの：3日の窓（昨日・今日・明日／空でも枠として要る）、今日以降の日付、
「いつでも」、コメントなどが残っている節。

## iPhone のホーム画面に置く

1. Safari で https://reiji55.github.io/task-3days/ を開く
2. 共有ボタン → **ホーム画面に追加**

アイコンが付き、Safari のバーが出ない全画面で開く。名前は「3日間タスク」。
アイコンの元は [`icon.svg`](icon.svg)。差し替えるときはここを直して PNG を作り直す。

### 画面が古いまま出るとき

ホーム画面のアプリは `index.html` を強く握るので、直しても端末には古いまま残る。
そこで **[`version.txt`](version.txt) だけは毎回取りに行き、`index.html` の
`<meta name="app-version">` と食い違ったら、URL に `?r=版` を足して読み直す。**
開き直したときにも見るので、放っておいても次に開いたときには新しくなる。

**`index.html` を直したら、この2か所を同じ値に揃えて上げること。**
揃っていないと、いつまでも読み直しが走り続ける（1セッションに1回で止まるが、
画面の右に「新しい版があります」と出たままになる）。

## 使い方

- **進んだらタップ**してチェックを付ける。メモもその場で書き換えられる
- **思いついたら入力欄に放り込む**。日付は決めなくていい（「いつでも」に入る）
- 日付を決める・まとめて入れ替えるときは Claude に頼む（`mcp/` のコネクタ経由）
- 手で直したいときは [`tasks.txt`](../../edit/main/tasks.txt) を GitHub 上で編集
- **今週の動きを見たい**ときは右の `週` に切り替える。予定はカレンダーの写し
- **やり方を書き残したい**ときは左の `ガイド`。タスクにせず、手順として置いておく

状態もメモも `tasks.txt` の中にあるので、次に相談するとき Claude がそのまま読める。
何が終わって何が残っているかも、そこから分かる。週の予定は `week.json`、
書き置きは `board.json` から読める。
