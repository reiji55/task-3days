# 3日間タスク

昨日・今日・明日の3日分だけを表示する、読み取り専用のタスクビューア。
`tasks.txt` を GitHub 上で編集すると、そのまま表示に反映される。

- 公開URL： https://reiji55.github.io/task-3days/
- 編集するファイル： [`tasks.txt`](../../edit/main/tasks.txt)

管理はしない。実体は Google カレンダー、詳細は Obsidian。ここは**見るだけ**。

---

## 書き方

```
# 2026-08-28
- [ ] 20:00-21:00 | 前進 | AIトレード | ステータスを整理する
  memo: 次のタスクを切り出すところまで
- [x] 終日 | ルーチン | 仕事 | 現場（未定）
```

| 位置 | 中身 | 省略 |
|---|---|---|
| `# YYYY-MM-DD` | 日付の見出し。この下に並べる | 不可 |
| `- [ ]` / `- [x]` | 未完了 / 完了 | 不可 |
| 1本目 `\|` の前 | 時間帯（`20:00-21:00`／`終日`／`午前`） | `-` で空欄 |
| 2本目 | 型（`前進` / `ルーチン`） | `-` で空欄 |
| 3本目 | プロジェクト名 | `-` で空欄 |
| 残り | タスク名 | 不可 |
| 次の行 `memo:` | メモ。複数行可 | 省略可 |

- `//` で始まる行はコメント。表示されない
- 3日の窓から外れた日付は「その他の日」に畳まれる。消さなくていい
- 日付の並び順は問わない

## 使い方

1. Claude に今日のタスクを出させる（この形式で）
2. `tasks.txt` を GitHub 上で編集して貼る
3. iPhone のブックマークから開く

メモは `tasks.txt` の中にあるので、次に流し込むときに Claude がそのまま読める。

## 注意

**このリポジトリは public。** URL を知らなくても検索で見つかる。
固有名詞（人名・会社名・金額）は書かない。案件名は「訴訟」「転職」程度に留める。
