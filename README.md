# 3日間タスク

昨日・今日・明日の3日分だけを表示するタスクビューア。
チェックとメモは画面から直接編集でき、`tasks.txt` に保存される。

- 公開URL： https://reiji55.github.io/task-3days/
- 編集するファイル： [`tasks.txt`](../../edit/main/tasks.txt)

管理はしない。実体は Google カレンダー、詳細は Obsidian。ここは3日分の作業台。

---

## 編集を有効にする（端末ごとに1回）

初期状態は読み取り専用。GitHub のトークンを端末に保存すると編集できるようになる。

1. [Fine-grained トークンを作る](https://github.com/settings/personal-access-tokens/new)
2. Repository access → Only select repositories → `task-3days`
3. Permissions → Repository permissions → **Contents** を **Read and write**
4. ビューアの「設定」を開いてトークンを貼り、保存

**トークンはこのリポジトリには入れない。** `index.html` は公開ファイルなので、書けば誰でも読める。
貼ったトークンは端末の localStorage に入り、GitHub にも他人にも渡らない。

有効期限が切れたら同じ手順で貼り直す。端末を手放すときは「設定 → 削除」。

## できること

| 操作 | 結果 |
|---|---|
| チェックをタップ | `- [ ]` ⇄ `- [x]` を書き換えて保存 |
| メモをタップ | メモを書き換えて保存。空にすると行ごと消える |
| `＋メモ` をタップ | メモのない行にメモを足す |
| 更新 | 読み直す。他の端末や GitHub 上での変更を取り込む |

行の追加・削除、時間帯やプロジェクトの変更は GitHub 上で `tasks.txt` を直接編集する。

保存は1回ごとに1コミット。誰が何をいつ変えたかは履歴に残る。
別の場所で先に更新されていた場合は保存せず読み直すので、上書きで消えることはない。

## 書き方

```
# 2026-08-28
- [ ] 20:00-21:00 | 前進 | AIトレード | ステータスを整理する
  memo: 次のタスクを切り出すところまで
- [x] 終日 | ルーチン | 仕事 | 現場（未定）
```

| 位置 | 中身 | 省略 |
|---|---|---|
| `# YYYY-MM-DD` | 日付の見出し。この下に並べる | 不可 |
| `- [ ]` / `- [x]` | 未完了 / 完了 | 不可 |
| 1本目 `\|` の前 | 時間帯（`20:00-21:00`／`終日`／`午前`） | `-` で空欄 |
| 2本目 | 型（`前進` / `ルーチン`） | `-` で空欄 |
| 3本目 | プロジェクト名 | `-` で空欄 |
| 残り | タスク名 | 不可 |
| 次の行 `memo:` | メモ。複数行可 | 省略可 |

- `//` で始まる行はコメント。表示されない
- 3日の窓から外れた日付は「その他の日」に畳まれる。消さなくていい
- 日付の並び順は問わない

## 使い方

1. Claude に今日のタスクを出させる（この形式で）
2. `tasks.txt` を GitHub 上で編集して貼る
3. iPhone のブックマークから開き、進んだらタップしていく

メモは `tasks.txt` の中にあるので、次に流し込むときに Claude がそのまま読める。
チェックの状態も同じファイルにあるので、何が終わったかも読める。

## 注意

**このリポジトリは public。** URL を知らなくても検索で見つかる。
固有名詞（人名・会社名・金額）は書かない。案件名は「訴訟」「転職」程度に留める。
